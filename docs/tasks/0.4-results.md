- Mac: `Mac17,8` (Apple M5 Pro), Version 27.0 (Build 26A428)
- Window on: Built-in Retina Display, 120 Hz max, backing scale 2×; measured display-link frame duration 8.33 ms
- Displays (`system_profiler SPDisplaysDataType`): Display Type: Built-in Liquid Retina XDR Display Resolution: 3456 x 2234 Retina Resolution: 2560 x 1440 (QHD/WQHD - Wide Quad High Definition)
- Window 1200 × 780 pt, 1,000,000 rows, per-cell styling on, one in-cell editor open
- Background load (1-minute load average at each run's start): median 4.2, range 2.5–24.8; the top processes before each run are in the bench log (see docs/tasks/0.4.md)
- **The screen was locked during all runs** (owner away): the app lays out, draws and commits every frame, but WindowServer does not composite the window. Numbers are main-thread cost; compositor/GPU hitches are not captured.

Metric definitions: *frame* = interval between display-link callbacks (vsync-quantised, so 8.33 ms = on time at 120 Hz); *>8.3* = frames that missed at least one refresh (interval > 12.5 ms); *>16.7* = missed two or more (> 20.8 ms); *busy* = main-thread time per frame (wall time minus run-loop sleep); *footprint* = `phys_footprint` (what `footprint(1)` reports, including graphics surfaces); *heap* = malloc bytes in use. Scroll stats pool the vertical, horizontal and wide-vertical phases; the jump to the end is reported separately.
